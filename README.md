# Hungry – Food Delivery App

Hungry is a simple, modern food delivery web app built with React and Vite. It features a sleek navigation menu, a functional search bar, and is designed to be easily extendable.

## Features

- Clean landing page design
- Navigation links: Home, Menu, Mobile App, Contact Us
- User authentication (Sign In)
- Shopping cart indicator
- **Functional search bar** in the header that lets users quickly search for menu items or content

## Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn package manager

### Installation

1. **Clone the repository**
git clone https://github.com/yourusername/hungry-food-delivery.git
cd hungry-food-delivery

2. **Install dependencies**
   npm install
   
4. **Start the development server**
npm run dev


5. **Open your browser**

Visit `http://localhost:5173/` to see the app.
